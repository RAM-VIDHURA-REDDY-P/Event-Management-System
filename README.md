# 📊 Event Management Analytics Dashboard – Power BI

## 📌 Project Overview

The **Event Management Analytics Dashboard** is an interactive business intelligence project built with **Microsoft Power BI**. It transforms event management data into clear visual insights to help monitor bookings, analyze event performance, and support data-driven decisions.

## 🎯 Objectives

- Monitor event bookings and booking statuses.
- Compare confirmed, cancelled, and pending bookings.
- Explore event performance through interactive visuals.
- Analyze revenue and trends where available in the dataset.
- Make insights easy to explore with slicers and filters.

## 🛠️ Tools & Technologies

| Tool | Purpose |
| --- | --- |
| Power BI Desktop | Dashboard development and reporting |
| Power Query | Data cleaning and transformation |
| DAX | Calculated measures and KPIs |
| Excel / CSV | Source data (as applicable) |

## 📈 Dashboard Features

- **Booking status analysis:** confirmed, cancelled, and pending bookings.
- **KPI cards:** quick summary of key event metrics.
- **Interactive charts:** visual comparisons and distributions.
- **Date slicers:** filter the report by time period.
- **Additional filters:** explore different segments of the data.

## 🔄 Project Workflow

1. **Import data:** Load the event management dataset into Power BI.
2. **Clean data:** Check missing values, data types, and inconsistencies in Power Query.
3. **Transform data:** Prepare fields needed for analysis.
4. **Create measures:** Use DAX to calculate booking and performance KPIs.
5. **Build visuals:** Design charts, KPI cards, and slicers.
6. **Analyze insights:** Interpret patterns to inform event planning decisions.

## 🚀 How to Use

1. Clone or download this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open the `.pbix` report in the `Dashboard` folder.
4. If necessary, update the dataset source path and refresh the data.
5. Explore the dashboard using interactive slicers and filters.
